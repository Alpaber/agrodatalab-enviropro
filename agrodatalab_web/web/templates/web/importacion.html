Qué hace esta importación

  • Lee registros procesados del sistema EnviroPro.
  • Crea nuevos registros sin duplicar fechas ya existentes.
  • Genera alertas automáticas cuando el archivo lo indica.
  • Asocia recomendaciones técnicas a las alertas creadas.

Indicaciones

  • El archivo debe estar en formato CSV.
  • Se recomienda usar el dataset limpio y procesado del análisis previo.
  • Los registros importados pueden generar alertas y recomendaciones automáticas.
  • Si un registro ya existe con la misma fecha y hora, no se duplicará.
  • La importación debe usar datos EnviroPro, no es necesario cargar información IFAPA-RIA en la web.
