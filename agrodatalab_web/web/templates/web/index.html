AgroDataLab EnviroPro

Esta aplicación forma parte del proyecto intermodular Horizonte Verde Digital.

El objetivo de AgroDataLab EnviroPro es transformar datos reales de sensores de suelo en información útil para entender la humedad del suelo, la temperatura del suelo y el estado energético del nodo EnviroPro.

A partir de estos datos se generan indicadores, se detectan situaciones de riesgo relativo, se crean alertas automáticas y se formulan recomendaciones prudentes, apoyadas por un modelo predictivo sencillo entrenado en la parte de análisis de datos.

Qué puedes hacer en la web
  • Consultar el dashboard general de EnviroPro.
  • Revisar registros resumidos de sensores.
  • Ver alertas automáticas y su nivel de riesgo relativo.
  • Gestionar recomendaciones asociadas a las alertas.
  • Importar nuevos datos limpios desde un archivo CSV.

Datos EnviroPro

El sistema EnviroPro registra fecha y hora de cada medición, humedad media del suelo, temperatura del suelo (media, máxima y mínima) y valores energéticos de batería y panel solar. La aplicación ha sido diseñada para adaptarse a nuevas descargas de datos, sin depender de un número fijo de registros.

Alcance de las recomendaciones

Las alertas y recomendaciones se entienden siempre como indicadores de riesgo relativo, no como órdenes agronómicas definitivas. No se dispone de información completa sobre cultivo, riego aplicado o tipo de suelo, por lo que las decisiones finales deben tomarse siempre junto al equipo agrario.
