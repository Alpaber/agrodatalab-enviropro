Acerca del proyecto

AgroDataLab Web es la aplicación desarrollada para visualizar información procesada del sistema EnviroPro dentro del proyecto intermodular Horizonte Verde Digital.

Finalidad de la aplicación

Esta aplicación web tiene como objetivo transformar datos reales de sensores en información útil para consultar el estado general del sistema, revisar indicadores principales, detectar alertas y mostrar recomendaciones asociadas.

La plataforma se centra en los datos de EnviroPro y permite presentar de forma clara registros, alertas, recomendaciones e importaciones de datos procesados en una interfaz web sencilla.

Tecnologías

  • Python para tratamiento y análisis de datos.
  • Pandas y técnicas de limpieza de datos.
  • Django para el desarrollo de la aplicación web.
  • Bootstrap para la presentación visual.
  • Base de datos para almacenar registros, alertas y recomendaciones.

Qué integra este proyecto

Análisis de datos

Importación, limpieza, normalización, análisis exploratorio, creación de indicadores, generación de alertas y apoyo a un modelo predictivo sencillo.

Aplicación web

Visualización de resultados, consulta de registros, revisión de alertas, gestión de recomendaciones e importación de datos ya procesados.

Páginas principales

  • Inicio: presentación general del proyecto.
  • Dashboard: indicadores clave y resumen del sistema.
  • Alertas: listado de alertas detectadas y su estado.
  • Recomendaciones: gestión CRUD de recomendaciones asociadas.
  • Importación: carga de archivos CSV procesados.
  • Acerca del proyecto: explicación del enfoque intermodular y la solución desarrollada.

Alcance del sistema

Las recomendaciones mostradas por la aplicación deben interpretarse como orientaciones prudentes basadas en patrones detectados en los datos, no como órdenes agronómicas definitivas.

La posible comparación con datos agroclimáticos de IFAPA-RIA pertenece a la parte de análisis de datos y no es obligatoria dentro de la aplicación web Django.
